# herwin.my.id

Static personal portfolio for Herwindra Berlian, served by GitHub Pages.

- No build step: plain HTML, one stylesheet (`assets/css/site.css`) and one small script (`assets/js/site.js`).
- Neo-brutalist theme: Space Grotesk + IBM Plex Mono, bone/ink palette with electric and acid accents.
- Preview locally: `python3 -m http.server 8000`
